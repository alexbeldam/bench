# results

`smoke-1`, `smoke-2`, `smoke-3` and `smoke-tables.md` are SMOKE outputs (5,000 documents, 3 repetitions, a shared laptop, a 2-CPU engine
container). They only prove that the harness and the analysis run end to end. They are not results and must not be quoted.
Real runs are downloaded from the GitHub Actions artifacts into `results/<label>/` (see `../RUNBOOK.md`).
